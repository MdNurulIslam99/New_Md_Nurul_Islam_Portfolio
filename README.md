# Md Nurul Islam — Portfolio (Next.js)

Modern, unique dark-themed portfolio converted from Vite + React to **Next.js 15 (App Router)**.

## Features
- Unique glassmorphism dark UI with cyan/emerald accents
- Smooth Framer Motion animations
- Single-page scroll sections (Home, About, Skills, Services, Projects, Contact)
- Responsive design
- EmailJS contact form
- Typewriter effect
- Project details modal

## Getting Started

```bash
cd nurul-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Scripts
- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Icons
- EmailJS + SweetAlert2
